# game-gun

2D 頂視角槍戰網頁遊戲（Boss 頻繁登場版）— 純前端單檔案實作，開啟 `index.html` 即可遊玩。

## 特色

- **8 名可選英雄**：疾風、泰坦、先鋒、死神、幽靈、天使、火煞、影子，各有獨立的生命、速度、傷害倍率與被動能力
- **多樣化武器**：標準步槍、RPG、電磁貫穿砲、火焰噴射器、機槍、核彈發射器等戰爭武器，以及獵刀、斧頭、武士刀、重錘等近戰兵器，透過補給箱隨機取得
- **技能系統**：閃現、霰彈、震撼、雷射、焦油等主動技能，以及依擊殺數蓄能的大招
- **Boss 戰**：擊殺數達到門檻後會召喚泰坦巨獸、虛空領主等 Boss，並隨進度持續高頻刷新
- **幸運轉盤**：擊殺與開寶箱可累積抽獎次數，抽中傷害加成、狂暴、回血等獎勵
- **升級系統**：擊殺與拾取經驗提升等級，強化生命上限與傷害
- **跨裝置操作**：支援鍵盤滑鼠（WASD 移動、滑鼠瞄準/射擊、Space/Q/E/F/G/R 觸發技能），以及觸控雙搖桿（左移動、右瞄準）

## 執行方式

無需安裝依賴，直接用瀏覽器開啟 `index.html` 即可開始遊戲。

## 技術棧

- 純 HTML5 Canvas + 原生 JavaScript，遊戲邏輯全部位於 `index.html`
- UI 樣式使用 Tailwind CSS（CDN 版）
